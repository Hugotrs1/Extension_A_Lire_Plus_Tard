À lire plus tard → Discord

Dans Discord : paramètres du salon → Intégrations → Webhooks → Nouveau webhook → Copier l'URL du webhook. Garde cette URL secrète : n'importe qui la possédant peut écrire dans le salon.

Utilisation

  • Icône de l'extension : envoie la page avec une note facultative.
  • Clic droit dans une page web, ou sur un lien de la page → « Lire plus tard ». (Pas sur les onglets ni la barre d'adresse : Chrome ne le permet pas.)
  • Raccourci Alt+Shift+S : envoi direct, sans fenêtre (modifiable dans chrome://extensions/shortcuts).
  • Si du texte est sélectionné, il est ajouté en citation dans le message.
