# À lire plus tard

Extension Chrome / Edge qui envoie une page web dans un salon Discord, pour la lire plus tard.

## Fonctionnalités

- Envoi de la page en cours, avec une note facultative
- Clic droit dans une page web, ou sur un lien de la page → « Lire plus tard » (Chrome ne permet pas de l'ajouter au menu des onglets)
- Raccourci `Alt+Shift+S`
- Historique des derniers envois

## Installation

1. Crée un webhook Discord dans le salon voulu (**Modifier le salon → Intégrations → Webhooks**).
2. Ouvre `chrome://extensions`, active le **Mode développeur**, puis **Charger l'extension non empaquetée** → ce dossier.
3. Colle l'URL du webhook dans les options de l'extension.
